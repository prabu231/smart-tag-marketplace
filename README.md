# Smart Tag Marketplace

Marketplace repository containing the `smart-tag` plugin.

## Plugins

| Plugin | Skill | Description |
|--------|-------|-------------|
| `smart-tag` | `smart-tag-skill` | AI Smart Tagging for AEM assets with per-asset author approval, taxonomy add requests, and an Excel audit report. |

## Install

1. In Coworker, go to Customizations > Marketplaces > Add Marketplace and register this repository.
2. Once the status is Ready, go to Customizations > Plugins > Browse Marketplaces.
3. Select `smart-tag` and install.
